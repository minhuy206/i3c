\section*{Tổng kết \FunctionalCoverage{}}

Phần đầu của báo cáo \FunctionalCoverage{} trích xuất từ kết quả regression 81 test qua \gls{ucis}:

\begin{lstlisting}
I3C Functional Coverage Report
Tests analysed : 81
Closure bins   : 222/222 (100.0%)
Diagnostic bins: 173/173 (100.0%)
KPI policy     : crosses own closure.
                 component coverpoints are diagnostic
\end{lstlisting}

Với mỗi coverpoint và cross, báo cáo liệt kê từng bin kèm số lần hit và số test kích hoạt, ví dụ:

\begin{lstlisting}
Covergroup : i3c_correlated_coverage::cg_abort_termination
Cross      : cx_cause_point
Ownership  : Closure bins
Coverage   : 12/12  (100.0%)
  [HIT ] hc_abort,ccc                    count=  4 in 1 test(s)
  [HIT ] hc_abort,daa_assigned_address   count=  1 in 1 test(s)
  [HIT ] hc_abort,daa_id                 count=  2 in 1 test(s)
  ...
  [HIT ] reset,preamble                  count= 61 in 21 test(s)
\end{lstlisting}

\section*{Tổng kết SVA}

Phần đầu của báo cáo SVA tổng hợp trên cùng cơ sở dữ liệu coverage:

\begin{lstlisting}
I3C SVA Coverage Report
Tests analysed   : 81
Assertions       : 386
  PASS           : 386
  VACUOUS        : 0
  FAIL           : 0
  MISS           : 0
  WAIVED         : 0
  Closure        : 100.0%
Cover properties : 578
  HIT            : 578
  MISS           : 0
  WAIVED         : 1
  Closure        : 100.0%
\end{lstlisting}

Cover property được waive nằm ngoài mẫu số closure vì chỉ kiểm tra giá trị đọc lại của một địa chỉ
chưa ánh xạ cụ thể, không phải mục tiêu chức năng F1--F10:

\begin{lstlisting}
[WAIVED ] COVER cp_reset_readback_unmapped_020
reason=Raw readback of one specific unmapped address (0x020)
       is diagnostic, not a feature F1-F10 closure goal.
\end{lstlisting}
