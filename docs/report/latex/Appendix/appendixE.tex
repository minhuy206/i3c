\section*{Tổng kết Functional Coverage}

Phần đầu của report trích xuất từ coverage database qua UCIS sau khi merge 80 test:

\begin{lstlisting}
I3C Functional Coverage Report
Tests analysed : 80
Total bins     : 1639
Covered bins   : 1324
Overall        : 80.8%
\end{lstlisting}

Với mỗi coverpoint và cross, report liệt kê từng bin kèm số lần hit và số test kích hoạt, ví dụ:

\begin{lstlisting}
Covergroup : i3c_correlated_coverage::cg_abort_response
Coverpoint : cp_response
Coverage   : 6/6  (100.0%)
  [HIT ] hc_aborted           count=  30  in 6 test(s)
  [HIT ] nack                 count=  17  in 6 test(s)
  [HIT ] not_supported        count=   5  in 2 test(s)
  [HIT ] overflow             count=   1  in 1 test(s)
  [HIT ] short_or_bus_abort   count=  17  in 3 test(s)
  [HIT ] success              count=   2  in 1 test(s)
\end{lstlisting}

\section*{Tổng kết SVA}

\begin{lstlisting}
I3C SVA Coverage Report
Tests analysed   : 80
Assertions       : 411
  PASS           : 404
  VACUOUS        : 0
  FAIL           : 0
  MISS           : 7
  Closure        : 98.3%
Cover properties : 590
  HIT            : 577
  MISS           : 13
  Closure        : 97.8%
\end{lstlisting}

Bảy assertion trạng thái \texttt{MISS} (chưa từng được kích hoạt) được phân tích tại
\cref{sec:res-coverage}:

ap_cmd_wdata_stable_until_ready
ap_sdr_write_no_cmd_pop_except_continuation
ap_sdr_read_abort_toc0_blocks_continuation

ap_wroc1_continuation_waits_for_resp_ready
ap_i2c_never_enters_broadcast_header
ap_pad_model_turnaround_overlap_one_cycle
\end{lstlisting}
