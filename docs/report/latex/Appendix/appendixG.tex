\chapter{Hướng dẫn build và chạy mô phỏng}
\label{app:build}

Phụ lục này liệt kê các lệnh \texttt{make} để biên dịch và chạy môi trường kiểm chứng, bổ trợ cho
\cref{sec:ver-run}. Mọi lệnh chạy từ thư mục \texttt{src/verification/} với trình mô phỏng Cadence Xcelium
(\texttt{xrun}) và UVM 1.2.

\section*{Biên dịch và chạy một kịch bản}

\begin{lstlisting}[language=bash]
make compile                              # compile + elaborate
make sim SEQ=i3c_write_vseq               # run one Virtual Sequence
make sim SEQ=i3c_write_vseq DUMP_WAVES=1  # + waveform dump (waves/<SEQ>/)
make sim SEQ=i3c_write_vseq COV=1         # + coverage collection
make sim SEQ=i3c_write_vseq SEED=12345 VERBOSITY=UVM_HIGH
\end{lstlisting}

\section*{Các bộ hồi quy}

\begin{lstlisting}[language=bash]
make smoke            # one smoke test (i3c_imm_vseq)
make regression       # all 10 groups (80 tests)
make csr_regression   # 14 CSR tests
make fifo_regression  # 5 FIFO tests
make bus_regression   # 11 bus-level tests
make sdrw_regression  # 5 SDR write tests
make sdrr_regression  # 6 SDR read tests
make sdr_regression   # sdrw + sdrr
make imm_regression   # 4 Immediate Data tests
make i2c_regression   # 3 I2C tests
make ccc_regression   # 5 CCC tests
make daa_regression   # 6 DAA tests
make err_regression   # 21 response/error tests
\end{lstlisting}

\section*{Sinh report coverage}

Coverage database (\texttt{cov\_work/}) được merge qua các lần chạy với \texttt{COV=1}; hai target sau
build công cụ trích xuất dựa trên thư viện UCIS của Xcelium rồi sinh report dạng văn bản
(\texttt{coverage\_report.txt}, \texttt{sva\_coverage\_report.txt}) --- nguồn số liệu của
\cref{ch:results} và \cref{app:regression}:

\begin{lstlisting}[language=bash]
make tools            # build ucd2json / ucd2sva (UCIS API)
make cov_report       # functional coverage -> coverage_report.txt
make sva_cov_report   # SVA pass/miss      -> sva_coverage_report.txt
\end{lstlisting}

\section*{Tiện ích}

\begin{lstlisting}[language=bash]
make clean            # remove xcelium.d, logs, waves, coverage artifacts
\end{lstlisting}

\noindent Ràng buộc độ sâu FIFO không cần test riêng: \texttt{sync\_fifo} chứa assertion tại thời điểm
elaboration, dừng với thông báo \texttt{sync\_fifo: Depth (\%0d) must be a power of 2} khi cấu hình độ
sâu không phải lũy thừa của 2, minh chứng cho khẳng định biên dịch mô tả ở \cref{sec:rtl-queues}.
